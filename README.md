# 🛣️ Smart Pothole Reporting System

## 📌 Project Overview
Road potholes frequently remain unrepaired due to reporting delays and lack of precise location data. The **Smart Pothole Reporting System** addresses this civic safety issue by allowing citizens to upload road photos along with automatic GPS coordinates. The system uses computer vision to detect potholes, assess severity, and track the live status of repair work for municipal authorities and citizens.

## ⚡ Core Features
- **Auto-Geotagged Reporting:** Captures real-time GPS coordinates along with photo submissions.
- **AI-Powered Detection:** Filters false submissions and automatically identifies pothole size and severity.
- **Live Ticket Tracker:** Displays repair stages (`Reported` ➔ `In Review` ➔ `In Progress` ➔ `Repaired`).
- **Municipal Dashboard:** Visualizes high-density pothole areas on an interactive map.

## 🛠️ Tech Stack
- **Mobile App:** Flutter / React Native
- **Backend API:** Node.js / Python (FastAPI / Flask)
- **Computer Vision:** YOLOv8 / OpenCV
- **Database & Mapping:** Firebase / Google Maps API
